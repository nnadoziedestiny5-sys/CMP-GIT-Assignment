# CMP GIT Assignment

**Name:** Nnadozie Destiny

---

This project is a calculator mobile application built using React Native and the Expo framework. It was created as part of the practical Git assignment for our Computer Science programme.

## Core Features

- Addition, subtraction, multiplication and division
- Decimal number input
- Clear (AC) and backspace (C) buttons
- Equation display showing what's been entered so far
- Handles floating-point rounding correctly

## Colour Scheme

I chose a violet/purple accent colour for both the light and dark variants of the theme.

## Development

To run this locally:

1. Install dependencies with `npm install`
2. Start the development server with `npx expo start`
3. Open on device using Expo Go
